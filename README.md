# Bad Movies Overlay

Play video clips **on top of anything else on your screen**, with the background colour keyed out to transparent. Put info on screen while a movie plays in VLC.

## Install
Download the latest `BadMoviesOverlay-Setup-x.y.z.exe` from [Releases](../../releases/latest) and run it. Windows SmartScreen will warn (the app is unsigned): click **More info → Run anyway**. The app updates itself; click the green button when it appears.

## Use
1. **＋ Add clips** (or drag video files in). MP4 (H.264), WebM and MOV work best.
2. Open ⚙ on a clip, pause on a frame and **click the background colour** in the preview. Tune tolerance, edge softness and spill. Checkerboard = transparent.
3. Choose where it goes: display, X/Y/W/H, snap and size presets, or **Move & resize on screen** to drag the real overlay.
4. Click the tile (or press its hotkey) to show the clip; click again to stop. **Ctrl+Alt+Backspace** stops everything.

Overlays are click-through and sit above borderless-fullscreen players. Programs in exclusive fullscreen can't be covered.

## Where your data lives
`Documents\Bad Movies Overlay` (clips, thumbnails, `library.json`, daily backups). Updates and uninstalls never touch it.
